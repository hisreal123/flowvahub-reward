# Earn Rewards Page Reference

## Source
https://app.flowvahub.com/dashboard/earn-rewards

## Page Structure (Based on PRD Requirements)

### Layout
- Header section with title and description
- Tab navigation (Earn Points / Redeem Rewards)
- Main content area with cards/grid layout

### Components to Clone

1. **Point Balance Card**
   - Shows current point balance
   - Purple accent color (#9013fe / #9301fe)
   - Card with shadow and hover effects

2. **Rewards Journey Section**
   - Title: "Your Rewards Journey"
   - Left border accent in purple
   - Grid of reward cards

3. **Activity Cards**
   - Ways to earn points
   - Each card shows:
     - Activity name
     - Points value
     - Description
     - Action button

### Design Patterns
- Purple primary color: #9013fe / #9301fe
- Card shadows: `0_5px_15px_rgba(0,_0,_0,_0.05)`
- Hover effects: translate-y and shadow increase
- Border radius: 16px
- Border color: #f3f4f6

### Responsive Design
- Mobile: 1 column
- Tablet/Desktop: 3 columns grid
